## What it does

`main.py` writes one office joke to `/output/entry.txt`. The program is deterministic (the same bytes on every run), uses no network, and needs no input.

The line:

> Our standup ran so long the intern aged out of the internship, got promoted, and now runs the standup.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
